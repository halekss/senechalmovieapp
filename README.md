# Système de Recommandation de Films - Projet 2

## 📋 Description
Ce projet a été réalisé avec un groupe de 5 personnes. L'objectif était de créer un modèle de recommandation de films pour un cinéma de la Creuse qui peinait à faire revenir ses clients.

Suite à une étude de marché du département et de ses habitants en termes de consommation de films, les données extraites et nettoyées ont permis de réaliser un système de recommandation grâce à du Machine Learning.

Le code a été implémenté sur une application Streamlit fonctionnelle, et fait l'objet de ce dépôt Github.
